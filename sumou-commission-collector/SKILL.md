# 第三方佣金明细采集技能

**一键闭环**：素某后台导出代扣打款佣金明细 → Excel加工 → 重命名 → 上传企微微盘。全程只读平台，加工产物固定命名。

## 适用场景

- 每月1号定时导出上月佣金明细（调度器调用本技能）
- 用户要求拉取素某后台（console.sumou.fun）第三方佣金数据
- 佣金表加工（实到金额列）并上传企业微信微盘

## 前置条件

1. **浏览器登录态**：平台浏览器（CDP端口9222）需已登录素某后台。
   - 登录态cookie持久化约7-15天；失效时脚本自动读取 `~/.config/sumou-collector/credentials.json`（权限600，手机号+密码）自动登录；
   - 自动登录仍失败 → 退出码2，请求人工接管浏览器登录后重跑。
2. **wecom-cli**：已安装且授权（`wecom-cli auth show --status` 输出 `authorized`），微盘可见「豆包的共享空间」。

## 凭据安全存储（自动登录）

- 文件：`~/.config/sumou-collector/credentials.json`
- 格式：`{"username": "手机号", "password": "密码"}`
- 权限：600（脚本读取时若发现权限过宽会自动收紧）
- 约束：凭据只在本技能脚本内部使用，不输出、不入日志、不随GitHub同步

## 标准执行流程

```bash
python3 <技能目录>/scripts/run_collect.py
```

脚本自动完成：
1. 连接CDP浏览器（127.0.0.1:9222）
2. 打开 `https://console.sumou.fun/#/finance/flow`（财务中心-代扣打款）
3. 登录态检查：未登录 → 自动登录（手机号+密码+勾选协议）；失败 → 退出码2
4. 设置时间范围：**上月1号 ~ 本月1号**（如10月执行=9月1日~10月1日）
5. 点击导出，等待下载
6. Excel加工：**佣金列右侧新增"实到金额"列**，每行值 = 佣金 − 0.5
7. 重命名：**`<上月>月第三方佣金明细.xlsx`**（如10月1日执行=9月第三方佣金明细.xlsx）
8. 上传企业微信微盘「豆包的共享空间」根目录（**只上传最终加工表**）
9. 输出结构化JSON摘要（日期范围、行数、文件名、上传结果）

### 可选参数

```bash
python3 run_collect.py --date 20261001      # 指定执行日期（计算其上月1号~本月1号）
python3 run_collect.py --out <目录>          # 指定本地输出目录（默认 项目目录/产出物/第三方佣金）
```

## 产出物

```
<项目目录>/产出物/第三方佣金/<上月>月第三方佣金明细.xlsx
```

- 加工规则固定：佣金列右侧新增 `实到金额` 列，值 = 佣金 − 0.5（每行）；在实到金额列最后一行下方写入 `总计金额：<合计值>`（红色+26号粗体）
- 导出原始文件（.xls，实为xlsx内容）加工后统一保存为 .xlsx
- **企微云盘只上传最终加工表**（本地加工完成后单表上传）；**上传成功后立即删除本地表**（本地不留残留）

## 退出码与行动

| 退出码 | 含义 | 行动 |
| --- | --- | --- |
| 0 | 全流程成功 | 读摘要汇报（行数/文件名/微盘路径） |
| 1 | 页面/导出/加工/上传失败 | 读摘要中error字段排查；微盘上传失败可重试 |
| 2 | 未登录且自动登录失败 | 通过 interaction.request_action(browserControl) 请求用户接管浏览器登录素某后台，登录后重跑 |
| 3 | 环境错误（CDP不可用/缺依赖） | 检查浏览器与Python依赖 |

## 注意事项

- **微盘上传为"新文件上传"**：不支持覆盖/移动/删除，若重名会自动生成 `文件名(2).xlsx`，可先在企微客户端删除旧文件再跑。
- **ID不外露**：space_id/file_id等仅内部流转，回复用可读名称（空间名/文件名）。
- **时间口径**：始终"上月1号~本月1号"；文件名月份取**上月月份**（数据反映上月佣金），跨月自动计算。
