# 面谈功课固定结构（八大板块，顺序不变）

产物是给销售自己看的上场功课，不是给客户的方案。八个板块按此顺序排，编号 00–07，视觉沿用 `assets/template.html`。

## 00 先把这趟目标收窄
一句话主张 + 3 条"不"。第一次接触只立信任，不成交。
- 主张句式："这一次不卖方案，只让人记住你懂行、稳。"
- 3 条"不"从红线里挑最相关的：不劝自建/不踩对手、不报价不谈分成不承诺回本、不讲上架报名这类碎操作。

## 01 信任从哪来：两条腿走路
- **第一条 人稳（看不见但压人）**：别人说完再开口，停一两秒，不抢话不打断；问不到的直说回去核实，不硬编；全场不说"保证、一定、稳赚"；当场不驳任何人。
- **第二条 讲认知不讲碎活**：聊本质、聊规律、聊谁在跑；具体怎么上架怎么报名先藏着；观点要有判断，不和稀泥。

## 02 由点及面的叙述主线（六环，核心）
一环扣一环，从客户已认可的小事往大处带，每环配一块 amber 色"可以这么说"口播。环内需要对照时用左右小卡（没变的/变了的、传统/新渠道、机会/门槛）。

1. **从他已经认可的事切入**：接微信/截图里他承认过的资源（货源、门店、老客、渠道），先肯定这块是稀缺壁垒，他顺着就听进去。
2. **第一层 · 本质：零售这本账没变**。人货场（人=需求、货=供给、场=交易地）百年没变；赚钱三笔账：毛利结构、复购率、成本（进货/获客/履约）。这层不分线上线下，跟开超市同一本账。
3. **第二层 · 壳：场变成电商/算法场**。老场赌地段人流，新场靠算法分发+搜索+活动位把货推给需求方；这层运营指标：选品命中率、动销率、库存周转天数、单均履约成本。
4. **第三层 · 场景：卖的需求变了，核心拼履约**。计划采购（有空、比价、囤货、对时效不敏感）vs 应急即时（现在就要、30分钟内、对价格不敏感、看快/近/此刻有货）；这层核心是履约效率、有货率/订单满足率。闪电仓就是为应急场景盖的前置仓。

**一句话总纲（先背熟再开口）：这门生意 = 零售的本质（毛利/复购/成本这本账）+ 电商的壳（算法分发 + 选品命中率/动销/周转/单均成本）+ 应急的场景（履约效率/有货/时效）。**

### 标准指标分层（三层各归各，不要重复讲）
- **本质层（不变的底层账）**：毛利结构、复购率、成本（进货/获客/履约），所有零售通用。
- **壳层（线上运营天天调）**：选品命中率、动销率、库存周转天数、单均履约成本；辅助：缺货率/有货率、评分好评、曝光转化漏斗。
- **场景层（应急需求核心）**：履约效率（时效/30分钟达）、有货率/订单满足率、就近前置仓密度。
- 注意：毛利、复购是本质层的账，壳层只用线上数据优化，不重复定义；履约成本在本质层是成本项，在壳层量化成"单均履约成本"，是同一笔钱的两个视角。
5. **讲这个赛道谁在跑（行业案例）**：2–4 个可核实案例，每条 = 背景量级 + **做起来的核心原因**。分类讲（平台系下场 / 原生新品牌 / 存量改造 / 供应链转仓，按实际行业取舍），最后落一句"路径不同，终局都回到同一件事，先盘自己手里的牌"。
6. **落到客户的品类：机会和门槛都讲，再落回他身上停住**。机会（场景、客单、毛利、复购、耐不耐损耗），门槛（合规、价格体系不冲老盘、动销/临期/季节性），点出他手里最稀缺的供给资产，然后收："具体怎么接看实际情况，今天先聊个框架。"不急着说你能干什么。

## 03 整场怎么排顺序
先听（暖场让在场人先讲，多问他的经历和动机，自己少说）→ 再讲（由点及面把认知聊出来，像聊天不像演讲）→ 后答（进入提问逐个接，答不准记下来回去核实）→ 收口（怎么做被追问才点一句，往"看实际情况"收，不展开）。

## 04 大概率会被问到的问题
每条：问题 + 参考说法 + 可选 note（这条为什么这么答）。常见问法按行业替换，但答法骨架通用：
- 这行到底能不能赚？→ 赛道成立但不躺赚，取决于哪几件事，不替他拍结果，理性是先小范围验证。
- 自己做/加盟/自建哪个好？→ 没绝对答案看手里的牌，各有取舍，今天不定，回去摸清再对比。
- 投多少、多久回本？→ 现场不报，报了是拍脑袋，回去按实际算结构。
- 你们做什么、怎么收费？→ 今天先不聊钱，只讲你负责哪段，合作等他判断值得做再谈。
- 会不会乱价/冲击我现有盘子？→ 先承认顾虑合理，专做增量、价格体系错开，具体边界要看他现有体系。
- 你们做过我们这行吗？→ 没有就直说，方法换品类是通的，让他自己判断，不编案例。
- 流量是不是一直花钱买？→ 测试期可能投，长期靠自然复购，投放只是敲门。
- 我们自己不能做吗？→ 能做，算上时间和试错成本，你是接他不熟的那段。

## 05 双方商业合作的博弈（心里算，不说出口）
双栏：
- **客户视角**：对他有利（补短板、放大资产、轻资产、少踩坑）+ 顾虑和隐性算盘（花钱没效果、怕被绑定、怕冲老盘、交数据后被动、想先让你搭好再自己接手、怕被练手）。
- **你的视角**：对你有利（绑定有资源方、沉淀可复制案例、轻投入）+ 风险点（不懂品类易露怯、效果不全在你、做完易被替换、前期重投入收费收不回、一上来谈股权易被拒）。
- **行动与表达策略** 8 条左右：先给价值再谈条件；收费分层保护前期重投入（基建一次性费 + 运营期月费/提点分开，不按低价单店打包）；从可复制/区域视角谈，不按一个店卖完整基建；边界写清（你对线上动作和结果负责，不背库存不碰定价）；顾虑前置；补位不替代；底牌留一半；节奏克制，条件留到他主动问。

## 06 让你显得稳的小动作（chips）
听完停两秒再答 / 不会就说回去核实 / 专业词后跟一句人话 / 不抢话不驳在场人 / 少说"保证、一定" / 案例只说量级不背精确数 / 被追方案往"看实际情况"收。

## 07 这趟别碰的线（redbox）
不主动推自建、不踩加盟品牌；不报价不谈分成不承诺销量回本；不讲碎操作；不懂的品类不装懂，让给客户讲；不编案例数字，企业自报 GMV 不当事实承诺。

## 调研核对清单（动笔前补齐）
- [ ] 客户：城市/区域、身份、已有资源、态度阶段、未摸底空白
- [ ] 品类本质：没变的三本账（选品/毛利/复购 或 获客/履约/周转）
- [ ] 传统 vs 新渠道对照（客群、需求、指标、获客方式）
- [ ] 2–4 个案例，每个都有可核实量级 + 崛起核心原因
- [ ] 机会点 + 门槛各至少 2 条
- [ ] 双方利弊各 4–5 条，策略保护自身前期投入
