# F.LUX 每日复盘与自我进化

**一键闭环**：全局系统检查 → 汇总问题 → 更新角色记忆 → 生成复盘报告 → 上传飞书 → 企微通知汇报。

## 快速开始

```bash
python3 <技能目录>/scripts/run_review.py \
  --date 20260918 \
  --cron-job-id 11357644891394 \
  --upload \
  --notify
```

## 核心功能

### 1. 全局系统检查

自动检查当日系统运行状态：
- **任务触发监控**：通过 get_cron_job 查询调度器最近运行时间，对比计划任务时间表，检查是否有任务未触发或延迟超过30分钟
- **执行完整性**：当日计划任务是否都执行，有没有遗漏或跳过
- **流程顺畅性**：任务之间跳转是否顺畅，有没有执行失败导致后续受影响
- **逻辑漏洞**：任务提示词中的执行步骤是否有逻辑漏洞
- **产出物检查**：当日产出物是否生成、是否上传到正确文件夹

### 2. 问题汇总

基于全局检查结果，汇总真实存在的问题（技术/流程/质量/架构），每个问题标注严重程度和验证结果。

### 3. 角色记忆更新

将当日工作内容、产出、问题、优化建议追加到角色记忆文件。

### 4. 复盘报告生成

按固定8章节模板生成Markdown复盘报告：
1. 今日任务执行情况
2. 全局系统检查（核心）
3. 各任务复盘摘要
4. 问题汇总
5. 优化建议（汇报请示用）
6. 角色记忆更新
7. 明日重点关注事项
8. 自我进化总结

### 5. 飞书上传

将复盘报告上传到飞书云空间 `产出物/每日复盘/` 文件夹（folder_token: EkcJftWXClQ4lCduIrncmenUnNb），使用单独临时目录上传。

### 6. 企微通知

通过企业微信通知用户（称谓"老大"），内容包含：
- 今日执行任务数、成功/失败数
- 全局检查发现的真实问题数
- 优化建议摘要（请示用户是否同意优化）
- 调度器跳转状态

## 命令行参数

| 参数 | 说明 | 默认值 |
|---|---|---|
| `--date` | 复盘日期（YYYYMMDD），默认今日 | 今日 |
| `--cron-job-id` | 调度器任务ID，用于检查任务触发情况 | 11357644891394 |
| `--output-dir` | 报告输出目录 | /tmp/flux_review |
| `--upload` | 上传报告到飞书 | false |
| `--notify` | 发送企微通知 | false |
| `--dry-run` | 干跑模式（不上传不通知） | false |

## 输出

- 复盘报告Markdown文件：`F.LUX每日复盘_YYYYMMDD.md`
- 结构化JSON结果（stdout），包含问题列表、任务执行情况、优化建议等

## 与调度器的集成

07每日复盘任务中调用本技能：

```bash
# 1. 执行每日复盘（生成报告+上传飞书+企微通知）
python3 <技能目录>/scripts/run_review.py --upload --notify

# 2. 跳转下一个任务（由调度器query中的步骤8完成，不在技能内）
```

## 注意事项

1. **技能检测与GitHub同步不在本技能范围内**：由 flux-skill-validator 技能单独完成，07复盘任务中先调用 validator 再调用本技能
2. **不自动修改配置文件**：发现问题后只汇报请示，未经用户同意不修改任何配置文件
3. **跳转步骤不在技能内**：调度器跳转（步骤8）由调度器query中的逻辑完成，确保跳转优先执行
4. **全局视角**：不盲目相信执行日志，结合系统逻辑验证问题是否真的存在
