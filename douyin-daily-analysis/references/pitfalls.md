# 常见坑与解决方案（已验证经验）

## 一、抖音创作者后台相关

### 1. 登录态丢失
- **现象**：打开creator.douyin.com显示扫码登录页面，或数据中心显示"登录已过期"
- **处理**：立即通知用户重新登录，通过interaction.request_action让用户扫码
- **注意**：不要尝试绕过登录，不要用通用搜索代替后台数据
- **历史经验**：登录态通常能保持3-5天，9月16-18日连续3天丢失，9月18日用户扫码后恢复，此后连续保持

### 2. 首页弹窗干扰
- **现象**：登录后首页弹出"欢迎体验新版首页"引导弹窗（1/2、2/2）
- **处理**：点击"跳过"或"下一步"关闭弹窗，再进行数据采集
- **注意**：弹窗可能有2步，需要都关闭才能看到完整数据

### 3. 数据中心统计周期
- **现象**：数据中心默认显示"近7日"，但统计周期可能不是用户期望的
- **处理**：记录实际统计周期（如9.13-9.19），不要写"近7日"这种模糊表述
- **注意**：数据中心URL：https://creator.douyin.com/creator-micro/data-center/operation

### 4. 内容管理作品列表
- **现象**：内容管理页面可能有"评论管理""合集管理"等弹窗干扰
- **处理**：关闭弹窗后再采集数据
- **注意**：内容管理URL：https://creator.douyin.com/creator-micro/content/manage
- **作品数据字段**：播放量、点赞数、评论数、分享数、收藏数、完播率、2秒跳出率、5秒完播率（如有）、吸粉量

## 二、抖音热门视频搜索相关

### 1. 必须用抖音网页版直搜，禁用通用搜索
- **正确**：打开https://www.douyin.com，在搜索框输入关键词
- **错误**：用general_search搜索"抖音热门视频"
- **原因**：通用搜索返回的不是抖音平台的实时热门视频，数据不准确

### 2. 抖音网页版未登录状态下搜索功能强制要求登录
- **现象**：未登录时搜索会弹出登录窗口，且无关闭按钮
- **处理**：必须先登录抖音网页版，再进行搜索
- **注意**：抖音创作者后台登录态和抖音网页版登录态可能不通用，需要分别确认

### 3. 泛词搜索高赞短视频极少
- **现象**：用"反转""守店日常""打工人"等泛词，在"一周内+最多点赞+1分钟以下"筛选下，高赞短视频极少
- **处理**：
  - 放宽筛选条件（不限制1分钟以下，或不限制一周内）
  - 用更具体的关键词（如"象棋盲棋""麻将反转""实体店老板日常"）
  - 如果最近7天确实找不到5条高赞视频，可以用最近7-14天的视频，但必须标注发布时间
- **注意**：每条视频必须记录真实发布时间，不要编造

### 4. 视频数据记录要求
- 必须记录：标题、链接、发布时间、作者、时长、点赞数、评论数、分享数、收藏数
- 数据必须来自抖音网页版视频页面的公开可见数据，不要编造
- 如果某项数据看不到（如收藏数），标注"未公开"或"未显示"

### 5. 5条视频类型必须多元化
- 必须覆盖至少4种不同类型和风格
- 类型配比：搞笑反差类40%（2条）、真实记录类30%（1-2条）、情感共鸣类20%（1条）、正能量温暖类10%（0-1条）
- 不要5条都是搞笑类
- 优先选结构简单、容易翻拍、适合守店人+运营人设的视频

## 三、wecom-cli相关

### 1. 必须使用新版本路径
- **正确**：/home/user/.npm-global/bin/wecom-cli（版本1.2.1）
- **错误**：直接用wecom-cli（可能是旧版本1.1.0）
- **旧版本报错**："cli token expired"、"请升级CLI版本>=1.2.0"
- **检查版本**：/home/user/.npm-global/bin/wecom-cli --version

### 2. 使用前检查授权状态
```bash
/home/user/.npm-global/bin/wecom-cli auth show --status
```
- 输出`authorized` → 已配置，可以继续
- 输出`unauthorized` → 未配置，需要执行`wecom-cli auth init --noninteractive`

### 3. 智能文档页面追加
- 命令：
```bash
/home/user/.npm-global/bin/wecom-cli smartpage pages append --json '{"docid":"<docid>","page_id":"<page_id>","content_type":"markdown","file_path":"<文件路径>"}'
```
- 成功标志：status: success, errcode: 0, errmsg: ok
- 注意：page_id必须来自smartpage pages get的回包，不要自行编造
- 固定文档page_id：每日拍摄策划=zyqjZU，分镜头脚本=6Ag4k9

### 4. 微盘文件上传
- 命令：
```bash
/home/user/.npm-global/bin/wecom-cli disk files upload --json '{"folder_id":"<folder_id>","file_path":"<本地文件路径>"}'
```
- 成功标志：返回file对象，包含id、file_name、path等
- 固定备份folder_id：fiz9h33ph3TDtaBh49IM7gM6KQNMg4bnhmvdGqkLr56_n8XNZS_MgI3gTZRYJ_aV3S8r83lOd3pb_1M1Z9Wdae6A

## 四、企微群消息推送相关

### 1. 必须用python + urllib，不要用curl + %格式化
- **问题**：群消息内容里含"0%"等百分号，用curl -d '{"content": "...0%..."}'时，%会与shell格式化冲突，导致ValueError或推送失败
- **正确做法**：用python脚本，json.dumps序列化后推送
```python
import urllib.request
import json

webhook = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=95eccdcd-994b-4c57-a7e0-4ab7c502ce11"
content = "..."  # markdown内容
data = {"msgtype": "markdown", "markdown": {"content": content}}
req = urllib.request.Request(webhook, data=json.dumps(data).encode('utf-8'), headers={'Content-Type': 'application/json'})
with urllib.request.urlopen(req, timeout=10) as response:
    result = json.loads(response.read().decode('utf-8'))
```
- 成功标志：errcode: 0, errmsg: ok

### 2. 推送时机
- 必须在两个固定文档页面都追加完成后推送，确保文档链接可用
- 不要在文档追加失败时推送（群消息里的文档链接会打不开）

### 3. 群消息内容要求
- 标题：📊 抖音账号每日数据分析（YYYY年MM月DD日）
- 数据概览：最新作品播放量、点赞、评论、完播率、2秒跳出率（简洁列表）
- 问题诊断：3条以内核心问题
- 今日推荐选题：1个重点推荐选题，包含标题、参考视频链接、参考视频点赞数、核心亮点
- 文档链接：拍摄策划+分镜头脚本（指向固定文档）
- 结尾：一句话行动建议（今天就拍这个，拍完今天发）

## 五、内容创作相关

### 1. 时长控制
- 短视频必须控制在13-30秒，不要超过30秒
- 账号历史验证：13-21秒完播率28-35%，超过30秒完播率大幅下降
- 象棋盲棋系列虽然流量好，但第二集1分14秒完播仅11.44%，第三集2分39秒完播仅9.74%，第四集必须压缩到30秒内

### 2. 开头钩子
- 前3秒必须有钩子，否则2秒跳出率会很高（38-44%）
- 钩子类型：反差（0单但棋下得凶）、冲突（被指出错误）、悬念（下一步怎么走）
- 不要用缓慢的开场（如"大家好我是..."），直接进入冲突或反差

### 3. 互动引导
- 最后一帧必须有具体的、有共鸣的问题，不能泛泛"你怎么看"
- 好的互动问题："你们说他是真的棋艺高超，还是靠偷偷改棋赢的？觉得他棋艺高超的扣1，觉得他靠改棋的扣2"
- 坏的互动问题："你怎么看？""欢迎评论区讨论"
- 争议性问题引导站队，评论率更高

### 4. 人物立体
- 守店人不只是懒散嘴硬，还要有善良、努力、温暖的一面
- 不要把守店人刻画太蠢（用户明确批评过）
- 运营不只是灵魂拷问，还要有温暖、理解、陪伴的一面

### 5. 正能量
- 正能量要通过具体行动和细节体现，不要喊口号
- 例如：守店人虽然0单但还在默默整理货架、虽然嘴硬但会偷偷改棋（说明他在意）

### 6. 笑点
- 笑点要具体、夸张、有画面感，不要泛泛的反差
- 好的笑点："偷偷改棋被抓包，强装镇定说'我擦擦棋子，灰多'"
- 坏的笑点："守店人很懒"（没有具体画面）

## 六、其他注意事项

### 1. 不要每天创建新文档
- 所有内容都追加到固定智能文档「抖音账号运营总文档（帮主出发啦）」的对应页面
- 不要创建当日独立智能文档
- 拍摄策划追加到page_id=zyqjZU，分镜头脚本追加到page_id=6Ag4k9

### 2. 两个Markdown备份都必须上传微盘
- 拍摄策划和分镜头脚本都要上传到微盘「豆包的共享空间/抖音拍摄策划」文件夹
- 不要只上传一个

### 3. 数据必须真实
- 所有数据（播放量、点赞、评论、完播率等）必须来自抖音创作者后台的真实数据
- 不要编造数据
- 热门视频数据必须来自抖音网页版的真实公开数据
- 如果某项数据看不到，标注"未显示"或"未公开"

### 4. 称呼用户为"老大"
- 用户偏好称呼"老大"
- 群消息和回复中都用"老大"称呼

### 5. 实事求是，不夸大
- 用户明确批评过夸张表达（如"完全验证成功"）
- 要实事求是，不夸大，有什么说什么
- 数据改善就说改善，数据下降就说下降，不要粉饰
