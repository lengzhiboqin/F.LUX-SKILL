# 输出模板（拍摄策划 / 分镜头脚本 / 群消息）

## 一、拍摄策划Markdown模板

文件命名：抖音拍摄策划（YYYY年MM月DD日）.md
保存路径：项目主目录
开头必须加日期分隔线：

```markdown
---
## YYYY年MM月DD日
---
```

### 结构

1. **数据概览**
   - 账号总览（近7日）：播放量、互动率、完播率、作品数、粉丝净增（含同类作者对比、较昨日变化）
   - 作品数据（近7天）：总播放、总点赞、总评论、总分享、5秒完播率、2秒跳出率、封面点击率、平均播放时长
   - 粉丝数据：总粉丝、粉丝净增、吸粉量、脱粉量、获赞
   - 最新作品详细数据：标题、发布时间、时长、播放、点赞、评论、分享、收藏、完播率、2秒跳出率、吸粉量、评论内容（如有）

2. **重大发现与亮点总结**
   - 重大突破（如评论破0、涨粉、播放创新高）
   - 亮点总结（数据改善的指标、有效的内容元素）

3. **问题诊断（3条核心问题）**
   - 每条必须有数据支撑
   - 原因分析
   - 优化建议

4. **抖音热门视频分析（5条，覆盖至少4种类型）**
   - 搜索说明（搜索了哪些关键词、最近7天高赞短视频情况）
   - 每条视频记录：标题、链接、发布时间、作者、时长、点赞/评论/分享/收藏、核心结构、数据好的原因、可二创切入点
   - 类型配比：搞笑反差类40%、真实记录类30%、情感共鸣类20%、正能量温暖类10%

5. **选题推荐（5个，基于热门视频二创）**

   每个选题必须包含：
   - 选题标题（⭐标注重点推荐）
   - 参考视频（标题+链接+发布时间+作者+类型）
   - 参考视频数据（点赞、评论、分享、收藏、时长，必须真实数据）
   - 参考视频核心结构（1-2句话）
   - 参考视频数据好的原因
   - 二创内容（表格形式：时间、画面、台词/字幕三列）
   - 时长（XX-XX秒）
   - 互动引导（最后一帧字幕，具体有共鸣的问题，不能泛泛"你怎么看"）
   - 拍摄要点（3-5条具体指导）

6. **推荐优先级表格**
   - 列：优先级、选题、参考视频、参考视频点赞数、理由

7. **最终建议**
   - 1-2句话明确拍摄建议（今天先拍哪个，为什么）

---

## 二、分镜头脚本Markdown模板

文件命名：分镜头脚本-选题标题（YYYY年MM月DD日）.md
保存路径：项目主目录
开头必须加日期分隔线：

```markdown
---
## YYYY年MM月DD日：《选题标题》
---
```

### 结构

#### 脚本标题
```
# 分镜头脚本：《视频标题》

**总时长**：XX-XX秒
**风格**：（如搞笑反差+灵魂拷问+认怂）
**人物**：（如守店人（主演）、运营（第一视角，不出镜，只有声音））
**场景**：（如美妆外卖店店内，守店人坐在电脑桌前）
```

#### 每个镜头（必须包含7个字段）

```
## 镜头X（XX-XX秒）

| 项目 | 详细内容 |
|------|---------|
| **景别** | （中景/近景/特写/第一视角，详细说明画面范围） |
| **镜头语言** | （固定镜头/推镜头/快切/手持晃动/仰拍/俯拍，详细说明运镜方式） |
| **画面内容** | （详细描述人物动作、表情、道具、环境，具体到能直接拍） |
| **台词/字幕** | （详细写出每个人的台词，包括语气、音量、语速；屏幕字幕的位置、内容、样式） |
| **音效/BGM** | （详细说明BGM风格、起止时间、骤停/渐入；音效的具体内容和触发时机） |
| **演员指导** | （详细指导演员的表情、动作、语气、节奏，具体到能直接演） |
| **拍摄要点** | （3-5条具体注意事项，包括光线、道具、节奏、后期剪辑提示等） |
```

#### 整体拍摄要点总结（必须包含6个部分）

1. **节奏控制**：详细说明整个视频的节奏变化曲线（如前X秒慢、中间X秒加快、最后X秒变慢）
2. **音效关键节点**：列出所有关键音效/BGM变化的时间点和作用
3. **人物表情变化线**：详细列出主角从开头到结尾的表情/情绪变化曲线
4. **声音指导**：详细说明每个角色的声音特点
5. **道具准备**：列出所有需要准备的道具和场景布置
6. **后期剪辑要点**：列出后期剪辑的关键注意事项
