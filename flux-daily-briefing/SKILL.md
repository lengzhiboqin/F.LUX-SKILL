# F.LUX 每日经营简报（v2）

基于闪购数据管线产出的 **F.LUX品牌数据汇总表.xlsx**（8张表）生成每日经营简报。输出 Markdown **复杂版**（11章节全维度），文件名带 `v2` 标识。

## 数据源与口径（必须遵守）

- **数据源**：`F.LUX品牌数据汇总表.xlsx`（8张sheet），各表日期列：
  - 门店财务明细→`开始时间`、门店成交明细→`开始日期`、商品数据→`日期`、问题订单数据→`下单时间`、流量明细(新)→`日期`、流量渠道明细(新)→`日期`、评价数据→`评价提交日期`、售后订单数据→`下单时间`
- **日期格式**：CSV/Excel 中日期可能是 `20260915`（无分隔符）、`2026-09-15`（带横线）、`20260801-20260831`（区间，取前半）；统一用脚本内 `to_std_date()` 转换
- **净收入口径（必须一致）**：`收入 - 佣金 - 配送服务费 - 商家补贴金额 - 公益捐款 - 其他费用`（与历史03简报一致，不可直接用"收入"列）
- **取消率**：已取消订单 /（有效订单+已取消订单）
- **环比基准**：数据日期前一天

## 快速开始

生成昨日（如2026-09-15）简报：

```bash
python3 <技能目录>/scripts/generate_briefing.py \
  --excel <总表路径.xlsx> --date 20260915 --out <输出目录>
```

- `--date`：数据日期（`YYYYMMDD` 或 `YYYY-MM-DD`），通常为昨日
- 默认输出复杂版：`F.LUX每日经营简报_YYYYMMDD_v2_full.md`

## 复杂版章节（11章）

1. 品牌整体经营数据（营业额/实付/净收入/订单/客单价/佣金/取消/活跃门店）
2. 环比变化（昨日 vs 前日，4指标）
3. 门店营业额排名 TOP10（含TOP3贡献占比）
4. 门店净收入排名 TOP10（含净利率）
5. 商品销售 TOP10（销量/实付销售额/分类）
6. 流量分析（曝光/入店/加购/下单/新客，含漏斗转化）
7. 流量渠道分布（各渠道曝光/入店/下单/入店率）
8. 评价与售后（评分/差评/售后笔数/退款金额/售后类型/问题订单）
9. 异常门店识别（零订单门店/高取消率TOP5/整体取消率）
10. 关键发现与运营建议（亮点/风险/行动建议）
11. 辅助资料使用声明

## 格式规范

- 金额：`¥1,234.56`
- **环比变化带+号**（如 `+24.8%`）；**比率/占比/净利率不带+号**（如 `43.3%`、`4.3%`）
- 有效订单显示为整数+`单`（如 `201单`），不用金额格式
- 门店名称自动缩短（去掉品牌前缀和括号）
- 商品分类取 `||` 分隔最后一段
