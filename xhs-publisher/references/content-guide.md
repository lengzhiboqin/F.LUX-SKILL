## 二、内容格式要求

### 标题
- 知识干货型 + 数字 + 痛点，符合小红书爆款逻辑
- **20字以内**

### 正文
- 严格控制在 **900字以内**（建议 550-650字留余量）
- 分点论述 **4-6个知识点**
- 每个知识点包含：**是什么 + 为什么重要 + 怎么做**
- 加入 emoji 增加可读性
- 第一人称口吻，像过来人分享经验，有真实感，不说教

### 标签
- **5-8个**相关话题标签
- 包含大流量词（如 #创业）+ 精准词
- **标签放在内容的最后面**
- 用中性词：#开店日常、#小本创业 等
- **禁止**：#副业赚钱 等敏感词

### 结尾
- 金句总结 + 评论区互动引导
- **只做互动引导，不直接喊"私信我领资料"**，降低营销感
- 引流可放在评论区置顶

## 三、封面风格要求

### 统一风格（已验证高点击率）
- **真实场景背景**：美妆店货架、手机搜索界面、电脑屏幕、计算器账本等
- **超大粗体字标题**：白/红/黄三色搭配，带黑色粗描边
- **黑色笔刷涂抹标签条**：如"新手必看⚠️"、"干货收藏"
- **白色/黄色对话气泡贴纸**：如"搜不到"、"没流量"、"赚太少"
- 整体风格：真实、有冲击力、接地气，类似小红书避坑类爆款笔记封面

### 尺寸
- 竖版 **3:4 比例**（1536x2048）

### 禁忌
- 不要有任何小红书logo、官方标识、平台水印
- 纯原创设计
- 涉及证件类描述（如"营业执照"）易触发图片审核，改用文件夹/清单等中性表述

## 六、企微提醒配置（可选）

### 安装 wecom-cli
```bash
npm install -g @wecom/cli
wecom-cli auth init --noninteractive
# 扫码授权后即可使用
```

### 发送方式
通过 wecom-cli 发送 Markdown 消息。

### 配置
在 `config.json` 中配置：
```json
{
  "wecom": {
    "enabled": true,
    "chat_id": "你的企微会话ID或授权人ID",
    "cli_path": "wecom-cli"
  }
}
```
- `chat_id`：向授权人发消息时用授权人ID（通过 `wecom-cli identity whoami` 获取）；向其他会话发消息时先用 `wecom-cli message aibot sessions list` 获取会话列表中的 chat_id
- 授权人ID和会话ID属于内部标识，不要在公开场合展示

### Python 发送示例
```python
import json, subprocess
msg = {
    "chat_id": "你的chat_id",
    "msg_type": "markdown",
    "markdown": {"content": "消息内容"}
}
subprocess.run(["wecom-cli", "message", "aibot", "send", "--json", json.dumps(msg, ensure_ascii=False)])
```

### 命令行直接发送
```bash
wecom-cli message aibot send --json '{"chat_id":"你的ID","msg_type":"markdown","markdown":{"content":"消息内容"}}'
```

### 提醒消息模板
- 第一次提醒（内容生成后立即）："老大，今天第X期「标题」内容创作已完成，请审核并确认发布。"
- 第二次提醒（5分钟未确认）："老大，第X期「标题」请尽快确认发布，未确认将在5分钟后自动发布。"
- 自动发布成功通知："老大，第X期「标题」已自动发布成功。"

## 七、状态文件

### 路径
默认 `./publish_state.json`（可在 config.json 的 `state_file` 字段中配置）

### 内容结构
```json
{
  "issue": 10,
  "title": "笔记标题",
  "cover_path": "./output/cover_10.png",
  "body_path": "./output/body_10.txt",
  "created_at": "2026-09-16T10:35:00"
}
```

### 用途
- 记录当期内容路径
- 用户确认发布时读取，取消兜底任务
- 兜底任务触发时读取，获取内容进行检查/发布

## 八、输出目录

所有生成的文件保存在 `output/` 目录下（可在 config.json 的 `output_dir` 字段中配置）：

```
output/
├── cover_10.png       # 封面图
├── body_10.txt         # 正文（含标签）
└── ...
```

文件命名建议：`cover_<期数或日期>.png`、`body_<期数或日期>.txt`
