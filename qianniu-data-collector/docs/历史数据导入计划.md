## 二、历史数据导入方案

### 阶段一：闪购端历史数据导入（立即执行）

**目标**：把已有的50天闪购数据导入数据库

**步骤**：
1. 创建数据库和表结构
2. 建立门店映射表（先导入闪购端门店）
3. 逐表导入闪购端历史数据
4. 数据质量校验

**时间预估**：2-3小时（数据量不大）

---

### 阶段二：牵牛花端历史数据回溯采集

**分两类情况：**

#### 类型A：支持长时间回溯的表
（订单API、门店经营指标、品类分析、门店营业时长、门店商品指标明细、配送履约数据）

**回溯策略**：
- 从8月1日开始，每天跑一次采集脚本
- 每天采集完后自动入库
- 预计51天 × 每张表约1分钟 = 约1小时/表

**注意事项**：
- 牵牛花数据是否支持查询8月1日的数据？需要验证
- 任务中心可能有频率限制，需要控制速度
- 按天跑，不要一次跑太多

#### 类型B：仅支持近两周的表
（门店流量、商品流量）

**回溯策略**：
- 只能回溯近14天
- 从今天开始每天采集，逐步积累
- 历史数据缺失部分用闪购端的流量数据补充

---

### 阶段三：门店映射表对齐

**前提**：两边都有足够的历史数据后

**步骤**：
1. 导出两边所有门店名称
2. 做名称归一化：
   - 统一品牌名（F.LUX / F·LUX / f.lux）
   - 去掉多余空格
   - 统一括号格式
3. 做模糊匹配（编辑距离、关键词匹配）
4. 人工确认匹配结果
5. 建立永久映射表

**预期结果**：
- 完全匹配：25家
- 归一化后匹配：约30家
- 待人工确认：约15-20家

## 三、数据合并策略

### 时间对齐

```
时间轴：8月1日 ─────────── 9月21日 ──── 未来
          │                    │
          │ 闪购端数据全覆盖    │ 牵牛花端数据
          │                    │ 从9月21日开始积累
          └────────────────────┘
                │
                └── 重叠期：用牵牛花数据补充闪购端缺失的维度
```

### 数据合并原则

| 数据维度 | 主数据源 | 补充数据源 |
|---------|---------|-----------|
| 财务数据（收入/成本/利润） | 闪购端 | - |
| 成交指标（订单数/GMV） | 闪购端 | 牵牛花端（交叉验证） |
| 流量数据（曝光/入店） | 闪购端 | 牵牛花端（交叉验证） |
| 商品销售明细 | 闪购端 | 牵牛花端（补充缺货缺勤） |
| 配送履约 | 牵牛花端 | - |
| 营业时长 | 牵牛花端 | - |
| 品类分析 | 牵牛花端 | - |
| 评价/售后 | 闪购端 | - |

## 四、导入顺序

### 第一步：数据库初始化
1. 创建SQLite数据库
2. 建立表结构
3. 创建索引

### 第二步：闪购端数据导入
1. 导入门店主数据（闪购端门店列表）
2. 按表导入：
   - 门店财务明细
   - 门店成交明细
   - 流量明细
   - 商品数据
   - 问题订单
   - 评价数据
   - 售后订单
3. 数据校验

### 第三步：牵牛花端数据回溯
1. 验证牵牛花历史数据可回溯的天数
2. 按优先级回溯采集：
   - 高优先级：门店经营指标、门店商品指标明细、配送履约
   - 中优先级：品类分析、门店营业时长
   - 低优先级：其他
3. 每天采集完后自动入库

### 第四步：门店映射表完善
1. 牵牛花端门店入库
2. 自动匹配两边门店名称
3. 人工确认未匹配的门店
4. 建立永久映射表

## 五、对后续工作的影响

### 有影响的方面

1. **数据分析需要等数据积累**
   - 牵牛花端数据维度只有近两周可用
   - 长期趋势分析需要等数据积累
   - 8月1日-9月20日的牵牛花数据缺失，需要用闪购端数据替代

2. **门店映射是前置条件**
   - 没有门店映射表，两边数据无法关联
   - 门店映射表需要人工确认，需要老大配合

3. **回溯采集需要时间**
   - 51天 × 每张表约1分钟 = 约1小时/表
   - 9张表全部回溯约需半天到一天

### 没有影响的方面

1. **今天开始的每日采集不受影响**
   - 今天开始每天采集，数据持续积累
   - 历史数据回溯是并行的补充工作

2. **分析框架可以先搭起来**
   - 数据表结构设计不依赖历史数据
   - 分析脚本可以先写好，等数据齐了再跑
